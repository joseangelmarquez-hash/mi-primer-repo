# mi-primer-repo

Repositorio de práctica para aprender el flujo de trabajo con Git y GitHub: ramas, commits y pull requests.

## Excalidraw

Este repo incluye una pizarra [Excalidraw](https://github.com/excalidraw/excalidraw) (React + Vite).

```bash
npm install
npm run dev
```

Luego abre la URL que muestra Vite (por defecto http://localhost:5173).

# mi-primer-repo

Repositorio de práctica para aprender el flujo de trabajo con Git y GitHub: ramas, commits y pull requests.

## Skill: AI Website Cloner

Este repo incluye la skill `clone-website` de [AI Website Cloner Template](https://github.com/JCodesMore/ai-website-cloner-template) (MIT) en `.claude/skills/clone-website/`.
En Claude Code úsala con:

```
/clone-website https://ejemplo.com
```

Para instalarla de forma global en tu máquina, copia la carpeta a `~/.claude/skills/clone-website/`.
